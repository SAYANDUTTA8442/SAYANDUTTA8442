## Research

### Towards Causally Faithful Empathetic Dialogue Generation via Structured Appraisal Reasoning
> *Under Review · EMNLP 2026 (submitted via ACL ARR, May 2026)*  
> Srishti Gupta, Ayushman Sarkar, **Sayan Dutta** (3rd of 7), Shashank Vishwakarma, Rishikesh Raj, Arghya Jana, Nagandla Tarun Teja

Introduces **ECOT-ERG** — a structured reasoning framework that decomposes empathetic response generation into interpretable intermediate steps: emotional cause identification → dominant cause prioritization → controllability appraisal → empathy strategy-guided generation.

**My contributions:** ECOT-ERG pipeline architecture · modular emotion-prediction & cause-identification components · T5 fine-tuning (FP16 mixed precision) · DPO preference pair construction · 16 experimental ablation configurations · evaluation using BERTScore, EASE, Cause-F1

**Research Interests**

`Large Language Models` `Memory-Augmented AI` `Cognitive Architectures` `Causal Reasoning` `Empathetic Dialogue` `Continual Learning` `Efficient Inference` `Agentic AI`

## Featured Projects

### 🧠 Blix — Cognitive Agent Architecture
> *Independent · Ongoing since June 2024 · Python · PyTorch · FAISS · Pydantic*

A cognitive agent architecture that explores what it takes to build an AI system that reasons, remembers, and recovers from failure in a principled way. Started a full year before I entered IIT Patna.

- Hierarchical memory with temporal retrieval and confidence estimation
- Belief tracking and truth maintenance for knowledge consistency
- Failure memory, self-correction, and replanning
- Workspace-based coordination — attention, planning, verification, evaluation pipelines
- Fully local, privacy-preserving, consumer-hardware optimized

[![Repo](https://img.shields.io/badge/github-blix.ai-0f172a?style=flat-square&logo=github)](https://github.com/SAYANDUTTA8442/blix.ai)

---

### 🌱 ASES — Precision Agriculture Advisory Platform
> *Capstone Project I · Jan–May 2026 · Team of 4 · Python · Scikit-learn · Gemini API · Streamlit*

Crop and fertilizer recommendation using feature-normalized KNN over soil and environmental attributes, augmented with LLM-based advisory generation via the Google Gemini API. Modular pipeline: prediction → recommendation → natural-language advisory.

---

### 🗄️ TerSQL — Multi-Database CLI Client
> *Independent · Nov 2025–Jan 2026 · Python · v0.0.3 beta*

An intelligent CLI client unifying MySQL, PostgreSQL, and MongoDB with zero LLM API dependencies.

- Offline natural-language-to-SQL parsing (regex rule engine)
- Smart autocompletion pulling live schema from the connected database
- Query bookmarks, persistent history, fuzzy search (`Ctrl+R`)
- Safe / read-only mode guards against destructive queries
- Multi-format output: grid, psql, markdown, html, latex, json, csv
